# System Blocker 🛡️
A lightweight, cloud-hosted blocklist script that modifies your local `hosts` file to block unwanted sites.

## Usage
1. Download or clone this repository onto your machine.
2. Edit `blocklist.txt` on GitHub or locally whenever you want to update blocked domains.
3. Run the script with administrative privileges:
   - Windows: Run command prompt as Admin, then `python main.py apply`
   - Linux/Mac: `sudo python3 main.py apply`
